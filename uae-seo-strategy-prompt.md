#### 3C. Faceted Navigation & Filter SEO Controls
To avoid indexing duplicate or low-value parameter URLs generated by product filters:
- **Canonical Rule:** All filtered view URLs (e.g., `/en/occasions/birthday?price=500-1000&color=gold`) must feature a clean canonical tag pointing to the root category URL (`https://domain.ae/en/occasions/birthday`).
- **Robots Directives:** Include `noindex, follow` on complex dynamic search/filter parameter strings.
- **Indexable High-Value Attribute Combinations:** Create dedicated static landing pages for high-volume filter queries (e.g., `/en/collections/chocolate-gift-boxes`) rather than relying on dynamic search parameters.

#### 3D. Seasonal URL Lifecycle Strategy
- **Evergreen Permalinks:** Never include years or temporary tags in URLs (Use `/en/occasions/eid-gift-boxes`, NOT `/en/occasions/eid-2026`).
- **Off-Season Page State:** Keep seasonal URLs live 365 days a year. During off-season months, update the hero banner to display "Preview Next Season's Collection" or a pre-order waitlist form while retaining acquired backlinks and PageRank.
- **Pre-Season Ramping:** Update titles, metadata, and homepage featured links 6–8 weeks before the event to enable search engine crawlers to re-index and elevate ranking positions prior to peak search traffic.

#### 4C. Technical Core Web Vitals & Next.js Performance Targets
- **Image Optimization:** Enforce `next/image` with WebP/AVIF format conversion, explicit width/height parameters to prevent Cumulative Layout Shift (CLS), and `priority` flags on above-the-fold hero imagery.
- **Performance Thresholds:** Target Largest Contentful Paint (LCP) < 1.8s, First Input Delay / Interaction to Next Paint (INP) < 100ms, and CLS < 0.05 on 4G mobile networks.
- **Font Optimization:** Utilize `next/font/google` for zero layout shift font loading (`display: swap`).

#### 4D. RTL / LTR Coexistence Rules
- Set `<html lang="ar" dir="rtl">` on Arabic pages and `<html lang="en" dir="ltr">` on English pages.
- Utilize CSS logical properties (`margin-inline-start`, `padding-inline-end`) across layout components.
- Apply high-legibility Arabic typography tailored for Khaleeji aesthetic preferences (e.g., `IBM Plex Sans Arabic` or `Cairo`).
